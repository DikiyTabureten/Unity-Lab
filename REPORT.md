# Лабораторная: Particle System

## Кратко
Нужно было повторить пример с занятия (взрыв бочки TNT) и сделать три домашних эффекта на частицах: снег в сцене Winter, салют в Firework и исчезновение монетки в Platformer. Всё работает: бочка взрывается один раз при падении на землю, снег идёт метелью и ложится на объекты, салюты взлетают и разрываются цветными шарами, монетка при касании игрока исчезает со вспышкой искр.

## Как запустить и проверить
Все сцены лежат в `Assets/4.ParticleSystem/Scene/`.

| Сцена | Что сделать | Что должно произойти |
|---|---|---|
| `ТNT` (первая «Т» кириллическая) | Play | Бочка падает на землю и исчезает. Красно-жёлтая вспышка, 40 осколков с жёлтыми хвостами разлетаются во все стороны, там, где они бьются о землю, поднимается серый дым. |
| `Winter` | Play | Снег идёт с первого кадра наискосок вправо, отскакивает и копится на иглу, снеговике, камне, табличке и земле, потом тает. |
| `Firework` | Play | Три ракеты (красная, зелёная, синяя) по очереди взлетают с золотым хвостом и разрываются круглым салютом своего цвета. Повторяется бесконечно. |
| `Platformer` | Play, довести игрока до монетки (стрелки) | Монетка исчезает, на её месте разлетается кольцо золотых искр. Повторно её подобрать нельзя. |

## Задание 1. TNT — взрыв бочки при столкновении (пример с занятия)
**Что сделали:** скрипт `Explosion` на бочке и взрыв из четырёх систем частиц. Потом по ходу проверки сделали след осколков тоньше, направление вылета случайным, а взрыв однократным.

**Где:** `Assets/4.ParticleSystem/Scripts/Explosion.cs`; сцена `ТNT`, объект `TNT`.

**Как это работает:**
```csharp
public class Explosion : MonoBehaviour
{
    public ParticleSystem particle;   // ParticleSystemExRed, задаётся в инспекторе
    public SpriteRenderer sprite;     // дочерний Sprite бочки

    private void OnCollisionEnter2D(Collision2D other)
    {
        if (!sprite.enabled) return;                       // уже взорвались — второй раз не надо
        sprite.enabled = false;                            // бочка «исчезает»
        GetComponent<Rigidbody2D>().simulated = false;     // невидимая бочка больше не падает и не мешает осколкам
        particle.Play();                                   // запускает красный взрыв и всех его детей
    }
}
```
- `OnCollisionEnter2D` вызывается Unity, когда коллайдер бочки (Box Collider 2D + Rigidbody 2D) касается другого коллайдера, здесь — `Ground`.
- Без первой строки бочка, уже невидимая, падала набок, и каждый новый край, касавшийся земли, перезапускал `Play()`. Замер в Play Mode показал 9 перезапусков за 0.9 с, и осколков накопилось 180.
- Без `simulated = false` осколки, рождённые внутри коллайдера бочки, бились о него каждый кадр, и дым упирался в Max Particles 1000.

Иерархия:
```
TNT                         Rigidbody2D, BoxCollider2D, Explosion
├─ Sprite
└─ ParticleSystemExRed      Burst 15, Circle (Radius Thickness 0.5), Lifetime 1, Size ↓, альфа → 0, Order 1
   ├─ ParticleSystemExYellow  копия красного, Start Size 2, Order 2
   └─ ParticleSystemTrail     осколки: Burst 40, Speed 10, Gravity 1, Randomize Direction 1,
      │                       Trails (Width 0.3, материал Boom), Collision World/2D, Order 3
      └─ Ps                   дым: саб-эмиттер по Collision, Burst 1 × 3 через 0.2, Gravity −1,
                              Circle r 0.21, Arc 163.3, серый → белый, альфа → 0, Order 4
```
- `ParticleSystemTrail` сделан дочерним к `ExRed`, чтобы он тоже стартовал от `Play()`. Как он запускался на занятии, в видео не видно.
- Красный, жёлтый и дым используют `New Material 2` (белый кружок), цвет задан Start Color. `Boom` — жёлтый материал без текстуры, его частицы рисуются квадратами (скорее всего, это и были «квадратные штуки» на занятии, 52:20). Поэтому `Boom` стоит только как материал хвостов.
- Значения, неразборчивые в видео, подобраны: Start Size красного 3, Radius 1, осколки Size 0.3, дым Speed 1, Size 0.5.

**Ключевые понятия:**
- *Burst* — выброс сразу пачки частиц в заданный момент, в отличие от Rate over Time (поток в секунду).
- *Sub Emitter* — дочерняя система, которую родитель запускает по событию своей частицы (Birth, Collision, Death). Работает только с Burst.
- *Trails* — след за каждой частицей; нужен отдельный Trail Material в модуле Renderer.
- *Rigidbody2D.simulated* — галочка «участвует в физике»: если её снять, тело и его коллайдеры исчезают из физического мира.

**Что делалось вручную:** студент выбрал варианты решений (импорт TMP, удаление Missing Script, выключение физики бочки) и принял вид взрыва в Play Mode.

**Коммиты:**
- 4bc9905 ParticleSystem: TNT — взрыв бочки
- d996b12 ParticleSystem: TNT — тонкий след и случайное направление осколков
- f59d005 ParticleSystem: TNT — один взрыв, больше осколков, меньше лишнего дыма

## Задание 2. Winter — снег, который падает на объекты; метель в одну сторону
**Что сделали:** одна система частиц `Snow` без кода: снег идёт наискосок и ложится на иглу, снеговика, камень, табличку и землю.

**Где:** сцена `Winter`, объект `Snow` (позиция (−1, 9), над кадром).

**Как это работает:**

| Модуль | Значения | Зачем |
|---|---|---|
| Main | Looping, Play On Awake, **Prewarm**, Lifetime 8, Speed 1–2, Size 0.08–0.18, Start Rotation 0–360, Gravity 0.1, **Simulation Space World**, Max Particles 3000 | Постоянный эффект; Prewarm — снег уже идёт в первом кадре; World — упавшие снежинки остаются на месте. |
| Emission | Rate over Time 80 | Плотность снегопада. |
| Shape | **Single Sided Edge**, Radius 12, поворот Z 200° | Линия во всю ширину над камерой; наклон задаёт направление вылета вниз-вправо — это и есть метель. |
| Rotation over Lifetime | −45…90 | Снежинки кружатся вразнобой (как на занятии). |
| Color over Lifetime | альфа 1 до 80% жизни, потом → 0 | Лежащий снег тает, а не исчезает рывком. |
| Collision | **World, 2D**, Bounce 0.3, Dampen 0.6 | Снег отскакивает от PolygonCollider2D объектов и Tilemap-коллайдера земли и останавливается. |
| Renderer | `New Material 2`, Order in Layer 5 | Белые кружки поверх объектов. |

Почему не Circle и не Velocity over Lifetime:
- Circle рождает частицы внутри круга, то есть прямо в кадре, а снегу нужна линия над экраном.
- Velocity over Lifetime и Force over Lifetime толкают частицу всю жизнь, поэтому снег не ложился бы, а скользил по земле. Наклон Shape даёт только начальную скорость, после удара Dampen гасит её, и снег остаётся лежать.

Проверка: через ~10 с Play Mode на поверхностях лежало 133 снежинки (на иглу 40, на снеговике 13, на камне 4, на табличке 3, остальные на земле), внутри объектов — ни одной.

**Ключевые понятия:**
- *Simulation Space World* — частицы после рождения живут в мировых координатах и не двигаются вместе с эмиттером.
- *Collision → World, Mode 2D* — частицы сталкиваются с обычными 2D-коллайдерами сцены.
- *Dampen* — доля скорости, которую частица теряет при ударе; *Bounce* — сила отскока.
- *Prewarm* — система стартует так, будто уже отработала один полный цикл.

**Коммит:** 0c44c02 ParticleSystem: Winter — снег с коллизией и метелью

## Задание 3. Firework — салют: вылетают, разлетаются в разные стороны, красивые, яркие
**Что сделали:** три салюта разных цветов. Каждый — ракета с золотым хвостом и дочерний взрыв-саб-эмиттер, который срабатывает при смерти ракеты.

**Где:** сцена `Firework`, объекты `FireworkRed` (x −5), `FireworkGreen` (x 0), `FireworkBlue` (x 5), у каждого дочерний `Explosion`.

**Как это работает:**
```
FireworkRed / Green / Blue    ракета: Looping, Play On Awake, Duration 1.5, Start Delay 0 / 0.5 / 1,
│                             Burst 1, Speed 8–10, Lifetime 1.1–1.5, Gravity 0.6, World,
│                             Shape Circle Arc 40° вверх, Trails (Lifetime 0.4, материал Boom),
│                             Sub Emitters: Death → Explosion, Inherit Color, Order 2
└─ Explosion                  Play On Awake выкл., Burst 80, Speed 2–5, Lifetime 1–1.5, Gravity 0.3,
                              Shape Sphere, короткие Trails (New Material 2), альфа → 0 после 60% жизни, Order 3
```
- Ракета — одна частица за цикл. Когда её жизнь кончается (Death), саб-эмиттер в этой точке выбрасывает Burst 80.
- *Inherit Color*: взрыв белый, а цвет берёт у ракеты. Поэтому три копии отличаются только Start Color ракеты.
- Start Delay разведён, чтобы ракеты взлетали не одновременно.
- Shape взрыва — **Sphere**, хотя на занятии всегда ставили Circle. Саб-эмиттер поворачивает свою Shape по направлению полёта ракеты, и круг вставал к камере ребром: на первом прогоне взрыв выглядел линией. Шар разлетается во все стороны при любом повороте и в 2D-камере выглядит круглым.

**Ключевые понятия:**
- *Sub Emitter → Death* — запуск дочерней системы в точке, где умерла частица родителя.
- *Inherit Color* — частицы саб-эмиттера умножают свой цвет на цвет частицы-родителя.
- *Start Delay* — задержка перед стартом системы.

**Коммит:** ff99f0d ParticleSystem: Firework — три цветных салюта

## Задание 4. Platformer — эффект исчезновения монетки
**Что сделали:** скрипт `Coin` по образцу `Explosion`; на каждой монете дочерняя вспышка искр. На четырёх объектах `Coins` Missing Script заменён на `Coin`.

**Где:** `Assets/4.ParticleSystem/Scripts/Coin.cs`; сцена `Platformer`, объекты `Environments/Coins` (4 шт.), дочерние `ParticleSystemCoin`.

**Как это работает:**
```csharp
public class Coin : MonoBehaviour
{
    public ParticleSystem particle;   // дочерний ParticleSystemCoin
    public SpriteRenderer sprite;     // спрайт самой монеты

    private void OnTriggerEnter2D(Collider2D other)
    {
        sprite.enabled = false;                   // монетка исчезает
        GetComponent<Collider2D>().enabled = false; // второй раз не подобрать
        particle.Play();                          // вспышка
    }
}
```
- У монеты BoxCollider2D с **Is Trigger**: игрок проходит сквозь неё, а Unity вызывает `OnTriggerEnter2D`.
- Срабатывает, потому что у игрока `Body` есть Rigidbody2D (Dynamic) и обычный BoxCollider2D. Для триггера нужно, чтобы Rigidbody2D был хотя бы у одного из двух объектов.
- `ParticleSystemCoin`:
  - Play On Awake выкл., не Looping, Burst 30;
  - Shape Circle, Radius 0.3, Radius Thickness 0 — частицы рождаются по краю круга, получается кольцо;
  - Speed 3–5, Size 0.2–0.35, Lifetime 0.4–0.6, Gravity 0.3;
  - Size over Lifetime 1 → 0, Color over Lifetime альфа → 0;
  - золотой Start Color, `New Material 2`, Order in Layer 10.
- Эффект настроен на одной монете, на остальные положены копии.
- Missing Script на монетах был один и тот же (guid `d466fd58…`, единственное поле `transform`). В истории репозитория этого скрипта нет ни в одном коммите. Другие Missing Script в сцене (облака `Cloud_1`, `Environment_0`, кости персонажа `Character`) не трогали: от них в консоли предупреждения «The referenced script (Unknown) on this Behaviour is missing!», они были и до работы.

Проверка: MCP не умеет управлять персонажем, поэтому в Play Mode `Body` переносили к монете через MCP. Спрайт и коллайдер монеты выключились, появилось 30 искр.

**Ключевые понятия:**
- *Trigger (Is Trigger)* — коллайдер, который не мешает движению, а только сообщает о касании (`OnTriggerEnter2D`).
- *Missing Script* — компонент, чей скрипт удалён или не попал в репозиторий; Unity хранит пустой компонент со ссылкой на несуществующий файл.
- *Radius Thickness 0* — частицы рождаются только на краю фигуры.

**Коммит:** 1d096ca ParticleSystem: Platformer — эффект исчезновения монетки

## Вопросы на защите
1. **Как запускается взрыв бочки?** `OnCollisionEnter2D` в `Explosion` прячет спрайт и вызывает `particle.Play()` у `ParticleSystemExRed`; дочерние системы стартуют вместе с ним.
2. **Почему у взрыва и монетки выключен Play On Awake, а у снега включён?** Взрыв и монетка — эффекты по событию, их запускает код. Снег идёт постоянно, поэтому стартует сам и зациклен (Looping).
3. **Почему саб-эмиттер дыма и взрыва салюта настроен на Burst?** Саб-эмиттер должен выпустить пачку частиц в момент события. На занятии (1:00) с Rate over Time он ничего не выпускал, заработало только с Burst.
4. **Зачем Simulation Space World у снега?** Иначе частицы двигались бы вместе с объектом-эмиттером; в World они живут в мировых координатах и остаются лежать там, где упали.
5. **Что значит Collision → World + 2D?** Частицы сталкиваются со всеми 2D-коллайдерами сцены (Box, Polygon, Tilemap), а не с заданными вручную плоскостями.
6. **Почему бочка раньше взрывалась много раз?** Прятался только спрайт, тело оставалось; падая набок, оно касалось земли снова, и каждое касание вызывало `Play()`. Исправлено проверкой `if (!sprite.enabled) return;` и `Rigidbody2D.simulated = false`.
7. **Как три салюта получают разный цвет?** У ракет разный Start Color, а взрыв белый и наследует цвет ракеты через Inherit Color у саб-эмиттера.
8. **Почему взрыв салюта на Sphere, а не на Circle?** Саб-эмиттер разворачивает фигуру по направлению полёта ракеты; круг вставал ребром к камере, и взрыв был линией. Шар выглядит круглым при любом повороте.
9. **Почему монетка срабатывает как триггер?** У неё BoxCollider2D с Is Trigger, у игрока — Rigidbody2D и коллайдер. Триггерам нужен Rigidbody2D хотя бы у одного из участников.
10. **Зачем выключать коллайдер монеты после подбора?** Чтобы повторное касание не запускало эффект снова.

## Что можно было бы сделать иначе
- Метель можно сделать модулем Force over Lifetime по X, но тогда снег скользит по земле. Нужно гасить силу кривой к концу жизни или выключать снег через Lifetime Loss в Collision.
- Вместо трёх копий салюта — одна система со Start Color → Random Color: меньше объектов, но цвета нельзя задать по отдельности.
- Бочку и монету после срабатывания можно было удалять `Destroy(gameObject, время)`, когда эффект доиграет. Тогда в сцене не остаются невидимые объекты.
